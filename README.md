# MiniGame Site 🎮

Встраиваемая система управления двумя дисплеями через серийный порт с поддержкой прошивки микроконтроллера.

## Основные возможности

- **TFT Display (SPI)** — цветной дисплей для графики
- **OLED Display (I2C)** — монохромный дисплей для информации  
- **COM Port Communication** — управление через серийный порт
- **Firmware Upload** — программирование микроконтроллера

## Структура проекта

```
minigameSite/
├── firmware/           # Прошивка микроконтроллера (C++)
│   ├── main.cpp        # Основной код с классами управления дисплеями
│   └── platformio.ini   # Конфигурация сборки (Arduino UNO)
├── host/               # ПО для ПК (Python)
│   └── device_manager.py    # Управление устройством через COM
├── docs/               # Документация (скоро)
└── README.md           # Этот файл
```

## Быстрый старт

### Прошивка устройства

```bash
cd firmware
pio run -e arduino_uno -t upload
```

### Управление с ПК

```bash
python host/device_manager.py COM3
```

## COM Протокол

### Команды устройству

```
STATUS          # Проверка статуса
TFT:HEXDATA     # Обновить TFT дисплей
OLED:HEXDATA    # Обновить OLED дисплей
```

### Ответы устройства

```
READY           # Устройство готово
OK              # Команда выполнена
ERROR           # Ошибка выполнения
```

## Подключение

| Пин МК | Назначение | Дисплей |
|--------|-----------|---------|
| D10    | CS        | TFT     |
| D8     | DC        | TFT     |
| D11    | MOSI      | TFT     |
| D13    | SCLK      | TFT     |
| A4/SDA | SDA       | OLED    |
| A5/SCL | SCL       | OLED    |

## Требования

- Arduino IDE / PlatformIO
- Python 3.7+
- Зависимости: `pyserial`

```bash
pip install pyserial
```
